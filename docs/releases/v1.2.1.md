What is in it:
- a fix for a CUDA graph capture crash under torch 2.13's automatic garbage collection. torch 2.13 no longer collects before a capture, so a collection could start inside one, free an old graph and invalidate the capture ("operation failed due to a previous error during capture"); the engine then turned graphs off and ran eager kernels. Captures now run with the cyclic collector paused, and the caller's collector state comes back after each capture, also after a failed one. v1.2.0 has the bug.

No speed claims: the fix changes no kernel and no setting.
